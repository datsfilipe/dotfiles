# Krita color schemes

Goth themes from [Zoldyako-Krita-Themes](https://github.com/Zoldyako/Zoldyako-Krita-Themes)
by José Victor Dias Rodrigues (@zoldyako), vendored at upstream commit `f2f3288`.
MIT licensed — see `LICENSE`.

Two families, eight accents each:

- `Z Goth *` — near-black chrome (`25,25,26`), dimmed 53% text
- `Zoldyakos Goth *` — slightly lifted chrome (`28,25,29`), brighter text

Krita picks these up from `~/.local/share/krita/color-schemes`. Pick one under
Settings > Themes after a restart.
